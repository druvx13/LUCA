Get Started

Using LUCA is simple

1. Download

Copy the license text to a file named COPYING in your project root.

curl -o COPYING https://raw.githubusercontent.com/druvx13/LUCA/main/COPYING

2. Customize

Update the copyright year and name in the license file.

Copyright (C) 2026 Your Name

3. Add Badge

Add a LUCA badge to your README (optional).
