## Custom Badge URLs

You can customize badges further by using shields.io parameters:

- `?style=` - flat, flat-square, plastic, for-the-badge, social
- `?color=` - blue, green, red, orange, yellow, purple, brightgreen, etc.
- `?logo=` - Add a logo (from simple-icons)
- `?logoColor=` - Change logo color

Example:
```markdown
[![LUCA](https://img.shields.io/badge/License-LUCA-blue.svg?style=for-the-badge&logo=github)](https://github.com/druvx13/LUCA)
```

## Creating Your Own

Want to create a custom LUCA badge? Use shields.io:

1. Go to https://shields.io/
2. Use the "Badge" section
3. Set label to "License"
4. Set message to "LUCA" or "LUCA v1.0"
5. Choose your color and style
6. Copy the markdown or URL

**crates.io:**

## Badge Best Practices

### Do's ✅

- Place badges at the top of README
- Use consistent style across badges
- Link badges to relevant pages
- Keep badges up to date
- Use standard badge services (shields.io)

### Don'ts ❌

- Don't use too many badges (clutters README)
- Don't use broken or outdated badges
- Don't mix too many different styles
- Don't use misleading badge text
- Don't link badges to wrong targets

## Advanced Badge Customization

### Dynamic Badges

Create dynamic badges using shields.io endpoint:

```markdown
[![LUCA](https://img.shields.io/endpoint?url=https://yoursite.com/luca-badge.json)](https://github.com/druvx13/LUCA)
```

Where `luca-badge.json` contains:
```json
{
  "schemaVersion": 1,
  "label": "License",
  "message": "LUCA v1.0",
  "color": "blue"
}
```

### Custom Styling

Add custom parameters:

```markdown
[![LUCA](https://img.shields.io/badge/License-LUCA-blue.svg?style=for-the-badge&logo=opensourceinitiative&logoColor=white)](https://github.com/druvx13/LUCA)
```

Parameters:
- `style`: flat, flat-square, plastic, for-the-badge, social
- `logo`: any simple-icons logo name
- `logoColor`: hex color or name
- `labelColor`: background color for label
- `color`: background color for message

## Troubleshooting

### Badge Not Rendering

**Problem:** Badge shows as text instead of image

**Solutions:**
- Check markdown syntax is correct
- Verify URL is accessible
- Test URL in browser
- Check for special characters in URL

### Badge Link Not Working

**Problem:** Clicking badge doesn't navigate

**Solutions:**
- Verify link URL in markdown
- Check for typos in URL
- Ensure parentheses are properly closed
- Test link separately

### Badge Wrong Color/Style

**Problem:** Badge doesn't look as expected

**Solutions:**
- Verify style parameter
- Check color parameter spelling
- Review shields.io documentation
- Test different browsers
