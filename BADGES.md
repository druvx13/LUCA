## Custom Badge URLs

You can customize badges further by using shields.io parameters:

- `?style=` - flat, flat-square, plastic, for-the-badge, social
- `?color=` - blue, green, red, orange, yellow, purple, brightgreen, etc.
- `?logo=` - Add a logo (from simple-icons)
- `?logoColor=` - Change logo color

Example:
```markdown
[![LUCA](https://img.shields.io/badge/License-LUCA-blue.svg?style=for-the-badge&logo=github)](https://github.com/druvx13/LUCA)
```

## Combining with Other Badges

LUCA badges work great with other project badges:

```markdown
![Build Status](https://img.shields.io/badge/build-passing-brightgreen.svg)
[![LUCA License](https://img.shields.io/badge/License-LUCA-blue.svg)](https://github.com/druvx13/LUCA)
![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)
```

## Creating Your Own

Want to create a custom LUCA badge? Use shields.io:

1. Go to https://shields.io/
2. Use the "Badge" section
3. Set label to "License"
4. Set message to "LUCA" or "LUCA v1.0"
5. Choose your color and style
6. Copy the markdown or URL
